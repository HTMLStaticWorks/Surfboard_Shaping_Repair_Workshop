# Surfboard Shaping & Repair Workshop

A premium, modern, and fully responsive website template designed for surfboard shapers and repair workshops.

## Features
- **Modern Design**: Built with a 8px spacing system and premium aesthetics.
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop.
- **Dark/Light Mode**: Toggle between themes with local storage persistence.
- **RTL Support**: Built-in support for Right-to-Left languages.
- **Service Calculator**: Interactive tool for estimating repair and shaping costs.
- **Form Validation**: Client-side validation for contact and auth forms.
- **SEO Optimized**: Meta tags, semantic HTML, and structured data ready.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Google Fonts (Poppins, Inter)
- Font Awesome Icons

## How to Use
1. Clone or download the project files.
2. Open `pages/index.html` in your browser.
3. To customize colors, modify the CSS variables in `assets/css/style.css`.
